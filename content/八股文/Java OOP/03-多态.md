# 多态

### 多态：编译时与运行时

**概念**：多态（Polymorphism，"many forms"）指同一个动作有不同的实现方式；Java 有编译时多态（重载）和运行时多态（重写）两种

**一句话**：重载在编译期根据参数的声明类型决定调用哪个方法；重写在运行期根据对象的实际类型决定调用哪个实现，所以 `Animal a = new Dog(); a.sound()` 调用的是 Dog 的版本；子类既共享父类的功能，又能有自己的行为。

**详细解释**：
poly = many，morphs = forms，polymorphism = many forms。
Compile time：源代码被转换成可执行文件的时候，比如 file.java → file.class。
Runtime：可执行文件正在运行的时候，比如 for 循环正在执行。
编译时多态（overloading）：同一个类里多个同名方法，参数个数或类型不同，"形态"在编译期就确定了，能提高可读性。
运行时多态（overriding）：子类方法与父类方法同名、同参数、返回类型相同或协变；通过父类引用调用时，执行的是对象实际类型的版本。
两者结合时：先在编译期按声明类型选出重载版本，运行时再按实际类型分派重写方法。

**问题**：什么是多态？编译时多态和运行时多态有什么区别？

**答案要点**：
1. 多态：同一个动作有多种实现（many forms）
2. 编译时多态 = 方法重载，按参数的声明类型在编译期确定
3. 运行时多态 = 方法重写，按对象的实际类型在运行期确定
4. 父类引用指向子类对象时，调用的是子类重写后的方法
5. 好处：调用方只依赖父类型，新增子类不用改调用代码

**对比**：
| | 方法重载 Overloading | 方法重写 Overriding |
|---|---|---|
| 作用 | 提高可读性 | 为父类方法提供具体实现 |
| 发生位置 | 一个类内（也可以在父子类之间） | 有 IS-A 关系的两个类之间 |
| 参数 | 必须不同 | 必须相同 |
| 多态类型 | 编译时多态 | 运行时多态 |
| 返回类型 | 可以相同也可以不同 | 相同或协变 |

**常见陷阱**：
- ❌ 认为选择重载版本时看的是对象的实际类型
- ✅ 重载看参数的声明类型（编译期），重写才看实际类型（运行期）

**追问**：
- Q: 运行时多态是怎么实现的？
- A: JVM 通过动态分派：调用实例方法时根据对象的实际类型查找方法（HotSpot 用虚方法表 vtable 加速查找）

**代码题**：下面代码输出什么？

```java
class Dog {
    public String bark() { return "woof"; }
}
class Hound extends Dog {
    public String bark() { return "awoo"; }
}
Dog d = new Hound();
System.out.println(d.bark());
```

- [x] awoo
- [ ] woof
- [ ] woofawoo
- [ ] 编译错误

解析：d 的声明类型是 Dog，实际类型是 Hound；bark() 被重写了，运行时按实际类型调用 Hound 的版本。

**代码题**：下面代码输出什么？

```java
class Dog {
    public void bark() { System.out.print("woof "); }
}
class Hound extends Dog {
    public void bark(int num) {
        for (int i = 0; i < num; i++) System.out.print("woof ");
    }
}
Hound h = new Hound();
h.bark();
h.bark(2);
```

- [x] woof woof woof
- [ ] woof woof
- [ ] woof
- [ ] 编译错误

解析：bark(int) 和继承来的 bark() 参数不同，是重载而不是重写，Hound 同时拥有两个方法；h.bark() 打印 1 次，h.bark(2) 打印 2 次。

**代码题**：下面代码输出什么？

```java
class Animal { String sound() { return "..."; } }
class Dog extends Animal { String sound() { return "woof"; } }
class Vet {
    static String check(Animal a) { return "animal:" + a.sound(); }
    static String check(Dog d) { return "dog:" + d.sound(); }
}
Animal a = new Dog();
System.out.println(Vet.check(a));
```

- [x] animal:woof
- [ ] dog:woof
- [ ] animal:...
- [ ] dog:...

解析：选哪个 check 是重载，编译期按 a 的声明类型 Animal 选中 check(Animal)；方法里的 a.sound() 是重写，运行期按实际类型 Dog 调用，得到 woof。

**判断题**：
- ✅ 方法重载属于编译时多态 —— 调用哪个重载版本在编译期就确定了
- ❌ 通过父类引用调用被重写的方法，执行的是父类的版本 —— 执行的是对象实际类型（子类）的版本

### 方法重写的规则与静态方法隐藏

**概念**：子类定义了与父类同名、同参数、返回类型相同或协变的实例方法，就构成重写（override）；static 方法不能被重写，只会被隐藏（hiding）

**一句话**：重写要求方法名和参数列表相同，返回类型相同或是子类型（协变），访问权限不能更小；final 方法不能重写，private 方法对子类不可见；static 方法同签名时只是隐藏，调用哪个看引用的声明类型；字段也没有多态，访问哪个字段同样看声明类型。

**详细解释**：
When an overridden method is called through the subclass object, it will always refer to the version defined by the subclass.
Static method hiding：子类定义了和父类同签名的 static 方法，父类的版本被隐藏而不是被重写；通过父类类型的引用调用时，执行的仍是父类版本。
字段隐藏：子类定义和父类同名的字段，父类字段被隐藏；`Animal a = new Dog(); a.name` 读的是 Animal 的字段，因为字段访问在编译期按声明类型确定。
协变返回：父类方法返回 Animal，子类重写时可以返回 Dog。
建议加上 @Override，签名写错时编译器直接报错。

**问题**：方法重写有哪些规则？static 方法能被重写吗？

**答案要点**：
1. 方法名、参数列表必须与父类相同
2. 返回类型相同或是其子类型（协变返回）
3. 访问权限不能比父类更小，受检异常不能更宽
4. final 方法不能重写，private 方法对子类不可见
5. static 方法只能被隐藏，字段也只会被隐藏，二者都没有多态

**常见陷阱**：
- ❌ 认为子类同名字段会像方法一样"重写"父类字段
- ✅ 字段没有多态，通过父类引用访问的是父类的字段
- ❌ 重写时把 public 方法改成 protected
- ✅ 访问权限只能扩大，缩小会编译错误

**追问**：
- Q: 为什么建议重写时加 @Override？
- A: 编译器会检查父类里确实有这个方法，方法名或参数写错时直接报错，避免"以为重写了、其实是新方法"

**代码题**：下面代码输出什么？

```java
class Animal {
    String name = "animal";
    String getName() { return name; }
}
class Dog extends Animal {
    String name = "dog";
    String getName() { return name; }
}
Animal a = new Dog();
System.out.println(a.name + " " + a.getName());
```

- [x] animal dog
- [ ] dog dog
- [ ] animal animal
- [ ] dog animal

解析：字段没有多态，a.name 按声明类型 Animal 读取父类的字段；getName() 被重写，运行时调用 Dog 的版本，返回 Dog 的 name。

**代码题**：下面代码能编译吗？

```java
class Animal {
    public void eat() { }
}
class Dog extends Animal {
    protected void eat() { }
}
new Dog().eat();
System.out.println("ok");
```

- [ ] ok
- [x] 编译错误
- [ ] 抛出 IllegalAccessException
- [ ] 什么也不输出

解析：重写时访问权限不能缩小，父类是 public，子类改成 protected 会编译报错。

**代码题**：下面代码输出什么？

```java
class Animal {
    Animal create() { return new Animal(); }
}
class Dog extends Animal {
    @Override
    Dog create() { return new Dog(); }
}
Animal a = new Dog();
System.out.println(a.create().getClass().getSimpleName());
```

- [x] Dog
- [ ] Animal
- [ ] 编译错误
- [ ] 抛出 ClassCastException

解析：子类重写时把返回类型从 Animal 改成了它的子类 Dog，这是协变返回，合法；a 实际是 Dog，调用 Dog 的 create()，返回一个 Dog。

**判断题**：
- ✅ 重写方法的返回类型可以是父类方法返回类型的子类 —— 这叫协变返回类型
- ❌ 子类定义了同签名的 static 方法，就重写了父类的 static 方法 —— 那是隐藏，调用哪个看引用的声明类型
