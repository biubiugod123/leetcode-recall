# 抽象与封装

### 抽象（Abstraction）

**概念**：抽象是隐藏内部细节、只展示功能（Hiding internal details and showing functionality）

**一句话**：抽象让使用者只关心"能做什么"，不用关心"怎么做"，就像打电话不需要知道手机内部怎么处理；Java 里通过抽象类和接口实现抽象，好处是使用更简单，也更安全。

**详细解释**：
What：隐藏内部细节、展示功能。比如打电话时，我们不知道内部是怎么处理的。
How：通过 Abstract Class 或 Interface。
Why：隐藏不必要的东西，让使用者更方便（easiness）；隐藏软件的内部实现，提供安全性（security）。
在代码里的体现：调用方只依赖抽象类型（比如 `List<String> list = new ArrayList<>();`），换实现时调用方不用改。

**问题**：什么是抽象？Java 怎么实现抽象？

**答案要点**：
1. 抽象：隐藏实现细节，只暴露功能
2. Java 通过抽象类和接口实现抽象
3. 好处一：使用者只需了解必要的功能，更简单
4. 好处二：隐藏内部实现，更安全
5. 调用方依赖抽象类型，更换实现时不受影响

**常见陷阱**：
- ❌ 认为抽象只能用 abstract class 实现
- ✅ 抽象类和接口都可以实现抽象

**追问**：
- Q: 举一个 JDK 里抽象的例子？
- A: List 接口：调用方只用 add、get、size，不关心底层是数组（ArrayList）还是链表（LinkedList）

**判断题**：
- ✅ 接口是实现抽象的一种方式 —— 抽象可以通过抽象类或接口实现
- ❌ 抽象的目的是让使用者了解所有实现细节 —— 恰恰相反，是隐藏细节、只暴露功能

### 抽象类的规则与用途

**概念**：abstract class 表示一个通用的概念，定义部分行为（partial behavior），剩下的交给子类实现

**一句话**：抽象类可以有 0 个或多个抽象方法，抽象方法没有实现；抽象类不能被实例化，但可以作为引用变量的类型；子类没有实现全部抽象方法时必须也声明为 abstract；用它是为了强制子类采用统一的方法签名、防止被误实例化、并复用公共的属性和方法。

**详细解释**：
```java
abstract class Shape {
    abstract double area();            // 抽象方法，没有方法体
    void print() { System.out.println(area()); }
}
Shape s = new Shape();     // ❌ 不能实例化
Shape s = new Circle();    // ✅ 可以作为引用类型
```
Why Abstract Class：
1. 强制所有子类使用相同的方法名和签名
2. 子类可以按自己的需求灵活实现这些方法
3. 防止意外实例化（prevent accidental initialization）
4. 定义公共的属性和方法供子类复用
抽象类可以有构造器、实例变量和普通方法，构造器在创建子类对象时通过 super(...) 执行。

**问题**：抽象类有什么特点？为什么要用抽象类？

**答案要点**：
1. 包含 0 个或多个抽象方法，抽象方法没有实现
2. 不能被实例化，但可以作为引用变量的类型
3. 子类必须实现全部抽象方法，否则自己也要声明为 abstract
4. 可以有构造器、字段和普通方法
5. 用途：统一子类签名、防止误实例化、复用公共代码

**对比**：
| 接口 Interface | 抽象类 Abstract Class |
|---|---|
| 可以多实现，一个类能实现任意多个接口 | 不能多继承，一个类只能 extends 一个类 |
| 用 implements | 用 extends |
| 方法默认 public abstract | 方法可以是 public / protected / 默认，可以抽象也可以有实现 |
| 除 default / static 方法外没有实现 | 可以有部分或全部方法的实现 |
| 除 default / static 外的方法都要实现 | 只有抽象方法需要实现 |
| 变量隐式 public static final | 变量可以是任意访问修饰符，不必 static / final |
| 没有构造器 | 可以有构造器 |

**常见陷阱**：
- ❌ 认为抽象类不能有构造器，所以构造器里的代码不会执行
- ✅ 抽象类有构造器，创建子类对象时会先执行它
- ❌ 认为子类继承抽象类后可以只实现一部分抽象方法
- ✅ 只实现一部分的话，子类也必须声明为 abstract

**追问**：
- Q: 抽象类不能实例化，那它的构造器有什么用？
- A: 给子类调用：创建子类对象时通过 super(...) 初始化抽象类里定义的公共字段

**代码题**：下面代码输出什么？

```java
abstract class Shape {
    Shape() { System.out.print("Shape "); }
    abstract double area();
}
class Square extends Shape {
    double side = 2;
    Square() { System.out.print("Square "); }
    double area() { return side * side; }
}
Shape s = new Square();
System.out.println(s.area());
```

- [x] Shape Square 4.0
- [ ] Square Shape 4.0
- [ ] Square 4.0
- [ ] 编译错误

解析：抽象类不能直接 new，但可以作为引用类型；创建 Square 时先执行父类 Shape 的构造器，再执行 Square 的构造器；area() 被重写，返回 2 * 2 = 4.0。

**代码题**：下面代码能编译吗？

```java
abstract class Shape {
    abstract double area();
}
class Circle extends Shape { }
System.out.println("ok");
```

- [ ] ok
- [x] 编译错误
- [ ] 抛出 AbstractMethodError
- [ ] 什么也不输出

解析：Circle 没有实现抽象方法 area()，自己又不是 abstract，编译报错；要么实现 area()，要么把 Circle 声明为 abstract。

**判断题**：
- ✅ 抽象类可以一个抽象方法都没有 —— 抽象类包含 0 个或多个抽象方法
- ❌ 抽象类的变量都是 public static final —— 那是接口；抽象类的变量可以是任意访问修饰符

### 封装（Encapsulation）

**概念**：封装是把字段和方法组合成一个单元（类），并用访问修饰符隐藏数据

**一句话**：封装的做法是把字段设为 private，通过 public 的 getter / setter 等方法访问；这样外部无法直接改数据，方法里可以做校验，内部实现改了也不影响调用方；好处是数据隐藏、可复用、易维护、灵活。

**详细解释**：
What：Encapsulation means combining fields and methods into a single unit (class)；Encapsulation is hiding information → use access modifiers to do data hiding.
How：Making the fields in a class private and providing access to the fields via public getter methods.
```java
public class Account {
    private double balance;
    public double getBalance() { return balance; }
    public void deposit(double amount) {
        if (amount <= 0) throw new IllegalArgumentException("amount must be positive");
        balance += amount;
    }
}
```
Why：
Data hiding：保护敏感数据不被未授权访问
Reusability：封装好的代码可以被不同调用者使用
Maintainability：对封装单元的操作不会影响其他部分
Flexibility：内部逻辑的修改不会影响方法的调用者

**问题**：什么是封装？怎么实现？有什么好处？

**答案要点**：
1. 把字段和方法组合成一个类，并隐藏数据
2. 字段 private，通过 public 方法访问
3. 方法里可以做校验，保证数据合法
4. 好处：数据隐藏、可复用、易维护、灵活
5. 内部实现变化时，调用方不受影响

**常见陷阱**：
- ❌ 认为给每个字段都机械地加上 getter / setter 就是封装
- ✅ 封装的重点是控制访问：只暴露必要的方法，并在方法里保证数据合法

**追问**：
- Q: 字段设成 public 有什么问题？
- A: 任何地方都能直接改，无法校验数据，也无法在不影响调用方的情况下修改内部表示

**代码题**：下面代码输出什么？

```java
class Account {
    private double balance;
    public void deposit(double amount) {
        if (amount > 0) balance += amount;
    }
    public double getBalance() { return balance; }
}
Account acc = new Account();
acc.deposit(100);
acc.deposit(-50);
System.out.println(acc.getBalance());
```

- [x] 100.0
- [ ] 50.0
- [ ] 150.0
- [ ] 编译错误

解析：balance 被封装成 private，只能通过 deposit 修改；deposit 里做了校验，-50 被忽略，余额是 100.0。

**代码题**：下面代码能编译吗？

```java
class Account {
    private double balance;
}
Account acc = new Account();
acc.balance = 100;
System.out.println(acc.balance);
```

- [ ] 100.0
- [ ] 0.0
- [x] 编译错误
- [ ] 抛出 IllegalAccessException

解析：balance 是 Account 的 private 字段，在其他类里直接访问会编译报错，这正是封装的数据隐藏。

**判断题**：
- ✅ 封装可以让类的内部实现修改后不影响调用方 —— 调用方只依赖公开的方法
- ❌ 封装就是把所有字段都声明为 public —— 封装要把字段设为 private，通过方法控制访问

### 抽象 vs 封装

**概念**：抽象隐藏复杂的实现细节、只暴露必要的功能；封装把数据和方法捆绑在一个类里，并控制对数据的访问

**一句话**：抽象关注"外部能看到和使用什么"，属于设计层面；封装关注"内部的数据怎么藏起来、怎么受控访问"，属于实现层面。用手机举例：点 Call 按钮手机就拨号了，这是抽象；手机的系统、芯片、电池都装在机身里，这是封装。

**详细解释**：
Encapsulation bundles data and methods within one class, and controls access to the data.
Abstraction hides the complex implementation details, only exposes necessary features.
手机的例子：
Abstraction：When you tap Call button → phone dials.
Encapsulation：phone OS, chip, battery inside the phone.
两者经常一起出现：接口 / 抽象类定义"能做什么"（抽象），具体类用 private 字段和方法把实现藏起来（封装）。

**问题**：抽象和封装有什么区别？

**答案要点**：
1. 抽象：隐藏实现细节，只暴露必要功能
2. 封装：把数据和方法打包，控制对数据的访问
3. 抽象偏设计层面（做什么），封装偏实现层面（怎么保护数据）
4. 抽象用抽象类 / 接口实现，封装用访问修饰符实现
5. 手机例子：拨号按钮是抽象，装进机身的零件是封装

**对比**：
| | 抽象 Abstraction | 封装 Encapsulation |
|---|---|---|
| 关注点 | 暴露什么功能 | 隐藏数据、控制访问 |
| 层面 | 设计 | 实现 |
| Java 手段 | abstract class、interface | private 字段 + 公开方法 |
| 手机例子 | 点 Call 就拨号 | 系统、芯片、电池装在机身里 |

**常见陷阱**：
- ❌ 把两者都说成"隐藏"，说不出区别
- ✅ 抽象隐藏的是"实现复杂度"，封装隐藏的是"数据"

**追问**：
- Q: 一个类可以同时体现抽象和封装吗？
- A: 可以，比如 ArrayList 实现了 List 接口（抽象），内部的 elementData 数组是 private 的（封装）

**判断题**：
- ✅ 用 private 修饰字段属于封装 —— 通过访问修饰符隐藏数据
- ❌ 抽象和封装是同一个概念的两种叫法 —— 抽象关注暴露什么功能，封装关注隐藏和保护数据
