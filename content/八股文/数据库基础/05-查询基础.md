# 查询基础

### SELECT 与 WHERE 条件

**概念**：SELECT 选择要取的列，FROM 指定表，WHERE 用条件过滤行；WHERE 中常用 =、<>、>、<、BETWEEN、IN、LIKE、IS NULL，以及 AND / OR 组合

**一句话**：BETWEEN a AND b 包含两端；IN 匹配列表中的任意值；LIKE 中 % 匹配任意多个字符、_ 匹配恰好一个字符；判断空值必须用 IS NULL / IS NOT NULL，用 = NULL 或 <> 比较时 NULL 永远不会被选中；AND 的优先级高于 OR，混用时要加括号。

**详细解释**：
语法：`SELECT col1, col2, ..., colN FROM table_name WHERE condition(boolean_expression)`。
SELECT 后面可以写：* 所有列；table.* / alias.* 某张表的所有列；属性列表；数学表达式（1 + 3）；常量（'CPA'、3）；函数。
WHERE 子句：<attribute> = [value]；BETWEEN [value1] AND [value2]；IN ([value1], [value2], ...)；LIKE 'SST%'；LIKE 'SST_'；IS NULL / IS NOT NULL；AND、OR 组合；>、<、=、!= 等比较运算符；子查询。
不等于可以写 <> 或 !=（有的数据库只认其中一种）。
NULL 表示"未知"，和任何值比较的结果都是 UNKNOWN，WHERE 只保留结果为 TRUE 的行，所以 dept = NULL、dept <> 'IT' 都不会选中 dept 为 NULL 的行。
课件把 WHERE 描述成 "Specify a criteria to sort data"，WHERE 的作用其实是过滤，排序是 ORDER BY。

**问题**：WHERE 子句中有哪些常用的条件写法？判断 NULL 要注意什么？

**答案要点**：
1. 比较：=、<> / !=、>、<、>=、<=
2. BETWEEN a AND b 包含两端，IN (...) 匹配列表中任意值
3. LIKE：% 匹配任意多个字符（包括 0 个），_ 匹配一个字符
4. 判断空值用 IS NULL / IS NOT NULL，= NULL 永远不成立
5. AND 优先级高于 OR，混用时加括号

**对比**：
| 写法 | 含义 |
|---|---|
| salary BETWEEN 3000 AND 4000 | 3000 ≤ salary ≤ 4000 |
| dept IN ('IT', 'HR') | dept 是 IT 或 HR |
| name LIKE 'A%' | A 开头，长度任意 |
| name LIKE 'A_' | A 开头，总共两个字符 |
| dept IS NULL | dept 为空 |

**常见陷阱**：
- ❌ 写 WHERE dept = NULL 找空值
- ✅ 结果永远为空，要写 WHERE dept IS NULL
- ❌ 写 WHERE a = 1 OR a = 2 AND b = 3，以为是 (a = 1 OR a = 2) AND b = 3
- ✅ AND 先算，实际是 a = 1 OR (a = 2 AND b = 3)，要加括号

**追问**：
- Q: NOT IN 的列表里有 NULL 会怎样？
- A: x NOT IN (1, NULL) 等价于 x <> 1 AND x <> NULL，后者永远是 UNKNOWN，所以一行都查不出来

**代码题**：下面 SQL 执行后，最后一条查询的结果是什么？（每行用 | 隔开）

```sql
CREATE TABLE emp (name VARCHAR(10), salary INT, dept VARCHAR(10));
INSERT INTO emp VALUES ('Ann', 3000, 'IT'), ('Bob', 5000, 'HR'), ('Cat', 4000, 'IT'), ('Dan', 5000, NULL);
SELECT name FROM emp WHERE salary BETWEEN 3000 AND 4000 ORDER BY name;
```

- [x] Ann | Cat
- [ ] Cat
- [ ] Ann | Bob | Cat | Dan
- [ ] Ann

解析：BETWEEN 包含两端，3000 和 4000 都在范围内，所以 Ann 和 Cat 都被选中。

**代码题**：下面 SQL 执行后，最后一条查询的结果是什么？

```sql
CREATE TABLE emp (name VARCHAR(10), salary INT, dept VARCHAR(10));
INSERT INTO emp VALUES ('Ann', 3000, 'IT'), ('Bob', 5000, 'HR'), ('Cat', 4000, 'IT'), ('Dan', 5000, NULL);
SELECT (SELECT COUNT(*) FROM emp WHERE dept = NULL), (SELECT COUNT(*) FROM emp WHERE dept IS NULL), (SELECT COUNT(*) FROM emp WHERE dept <> 'IT');
```

- [x] 0 1 1
- [ ] 1 1 2
- [ ] 0 1 2
- [ ] 1 1 1

解析：= NULL 永远不成立，得 0；IS NULL 找到 Dan，得 1；dept <> 'IT' 只选中 Bob，Dan 的 dept 是 NULL，比较结果是 UNKNOWN，不会被选中，所以也是 1。

**代码题**：下面 SQL 执行后，最后一条查询的结果是什么？

```sql
CREATE TABLE codes (c VARCHAR(10));
INSERT INTO codes VALUES ('SST'), ('SST1'), ('SST12'), ('ASST');
SELECT (SELECT COUNT(*) FROM codes WHERE c LIKE 'SST%'), (SELECT COUNT(*) FROM codes WHERE c LIKE 'SST_');
```

- [x] 3 1
- [ ] 3 2
- [ ] 2 1
- [ ] 4 1

解析：'SST%' 匹配以 SST 开头的任意字符串，包括 SST 本身，共 3 个（ASST 不是 SST 开头）；'SST_' 要求 SST 后面恰好一个字符，只有 SST1。

**判断题**：
- ✅ BETWEEN 10 AND 20 包含 10 和 20 —— BETWEEN 是闭区间
- ❌ WHERE col = NULL 可以找出 col 为空的行 —— 必须用 col IS NULL

### GROUP BY、HAVING 与 ORDER BY

**概念**：GROUP BY 把某列值相同的行合成一组，配合聚合函数（COUNT、SUM、AVG、MAX、MIN）统计；HAVING 过滤分组后的结果；ORDER BY 对结果排序

**一句话**：执行顺序是 FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY，所以 WHERE 在分组前过滤行、不能用聚合函数，HAVING 在分组后过滤组、可以用聚合函数；COUNT(*) 统计所有行，COUNT(列) 不统计该列为 NULL 的行，SUM、AVG 也会忽略 NULL；ORDER BY 默认升序，DESC 降序。

**详细解释**：
GROUP BY：Used to combine similar values in column；HAVING：Filter conditions for aggregate data；ORDER BY：Display data in specific order。
课件例子：
```sql
SELECT COUNT(CustomerID), Country
FROM Customers
GROUP BY Country
HAVING COUNT(CustomerID) > 5
ORDER BY COUNT(CustomerID) DESC;
```
含义：按国家统计客户数，只保留客户数大于 5 的国家，按客户数从多到少排序。
写的顺序：SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY；执行顺序：FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY。
使用 GROUP BY 时，SELECT 里除了聚合函数，只应该出现分组的列（MySQL 的 ONLY_FULL_GROUP_BY 模式会强制检查）。
ORDER BY 可以按多列排序：ORDER BY dept, salary DESC。

**问题**：WHERE 和 HAVING 有什么区别？SQL 的执行顺序是怎样的？

**答案要点**：
1. GROUP BY 按列分组，常配合 COUNT、SUM、AVG、MAX、MIN
2. WHERE 在分组前过滤行，不能使用聚合函数
3. HAVING 在分组后过滤组，可以使用聚合函数
4. 执行顺序：FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
5. COUNT(*) 统计所有行，COUNT(列) 和 SUM / AVG 都忽略 NULL

**对比**：
| | WHERE | HAVING |
|---|---|---|
| 过滤对象 | 原始的行 | 分组后的结果 |
| 执行时机 | GROUP BY 之前 | GROUP BY 之后 |
| 能否用聚合函数 | 不能 | 能 |
| 例子 | WHERE salary > 3000 | HAVING COUNT(*) > 5 |

**常见陷阱**：
- ❌ 把聚合条件写在 WHERE 里：WHERE COUNT(id) > 1
- ✅ 执行 WHERE 时还没分组，聚合条件要写在 HAVING 里
- ❌ 以为 COUNT(col) 和 COUNT(*) 结果总是一样
- ✅ col 有 NULL 时，COUNT(col) 会比 COUNT(*) 少

**追问**：
- Q: 能在 WHERE 里用 SELECT 中定义的别名吗？
- A: 在 MySQL 中不能，因为 WHERE 比 SELECT 先执行，那时别名还不存在；ORDER BY 在 SELECT 之后执行，可以用别名

**代码题**：下面 SQL 执行后，最后一条查询的结果是什么？（每行用 | 隔开）

```sql
CREATE TABLE customers (id INT, country VARCHAR(10));
INSERT INTO customers VALUES (1, 'US'), (2, 'US'), (3, 'US'), (4, 'CN'), (5, 'CN'), (6, 'UK');
SELECT country, COUNT(id) FROM customers GROUP BY country HAVING COUNT(id) > 1 ORDER BY COUNT(id) DESC;
```

- [x] US 3 | CN 2
- [ ] US 3 | CN 2 | UK 1
- [ ] CN 2 | US 3
- [ ] US 3

解析：按国家分组后 US 3 个、CN 2 个、UK 1 个；HAVING 过滤掉只有 1 个客户的 UK；按数量降序排列。

**代码题**：下面 SQL 执行后，最后一条查询的结果是什么？

```sql
CREATE TABLE t (v INT);
INSERT INTO t VALUES (1), (NULL), (3);
SELECT COUNT(*), COUNT(v), SUM(v) FROM t;
```

- [x] 3 2 4
- [ ] 3 3 4
- [ ] 2 2 4
- [ ] 3 2 NULL

解析：COUNT(*) 统计所有行，得 3；COUNT(v) 不统计 NULL，得 2；SUM 忽略 NULL，1 + 3 = 4。

**代码题**：下面 SQL 执行结果是什么？

```sql
CREATE TABLE customers (id INT, country VARCHAR(10));
INSERT INTO customers VALUES (1, 'US'), (2, 'US'), (3, 'CN');
SELECT country FROM customers WHERE COUNT(id) > 1 GROUP BY country;
```

- [ ] US
- [ ] US | CN
- [x] 执行报错
- [ ] 查询结果为空

解析：WHERE 在分组之前执行，不能使用聚合函数 COUNT，执行报错；应该改成 GROUP BY country HAVING COUNT(id) > 1。

**判断题**：
- ✅ HAVING 子句中可以使用聚合函数 —— HAVING 在分组之后执行，过滤的是分组结果
- ❌ COUNT(column) 会把该列为 NULL 的行也计算在内 —— COUNT(column) 忽略 NULL，COUNT(*) 才统计所有行

### SELECT 中的函数与别名

**概念**：SELECT 中可以使用函数（NOW、CONCAT、COALESCE 等）计算结果，用 AS 给列或表起别名，别名只在这一次查询中有效

**一句话**：NOW() 返回当前日期时间；CONCAT 拼接字符串（MySQL 中只要有一个参数是 NULL 结果就是 NULL）；COALESCE 返回参数中第一个非 NULL 的值，常用来给空值提供默认显示；AS 是可选的，给列起别名让结果更易读，给表起别名让 JOIN 写起来更简短。

**详细解释**：
Functions can be used in SELECT：NOW()（Current datetime）；CONCAT(<attribute and string constants>)（Concatenates the values）；COALESCE(<attributes and constants>)（Returns the first non-NULL argument）；更多见 MySQL 内置函数。
AS：used to create a more meaningful name by renaming a column or table with alias；It's optional and only exists for the duration of the query。
```sql
SELECT first_name AS 'First Name', last_name AS 'Last Name'
FROM employees;

SELECT e.first_name, d.department_name
FROM employees AS e
JOIN departments AS d ON e.department_id = d.id;
```
MySQL 的 CONCAT 遇到任一参数为 NULL 就返回 NULL；想跳过 NULL 可以用 CONCAT_WS 或者给参数套 COALESCE / IFNULL。

**问题**：COALESCE 有什么用？AS 别名有什么作用？

**答案要点**：
1. COALESCE(a, b, c) 返回第一个非 NULL 的参数
2. 常用 COALESCE(col, '默认值') 给空值提供替代显示
3. CONCAT 拼接字符串，MySQL 中有参数为 NULL 时结果为 NULL
4. AS 给列或表起别名，只在当前查询有效，可以省略 AS 关键字
5. 表别名能简化多表查询中的列引用（e.first_name）

**常见陷阱**：
- ❌ 用 CONCAT(first_name, ' ', middle_name, ' ', last_name) 拼全名，middle_name 可能为 NULL
- ✅ 在 MySQL 中整个结果会变成 NULL，要用 COALESCE(middle_name, '') 或 CONCAT_WS
- ❌ 认为 AS 别名会修改表或列的真实名字
- ✅ 别名只在这一次查询的结果中生效

**追问**：
- Q: COALESCE 和 MySQL 的 IFNULL 有什么区别？
- A: IFNULL 只接收两个参数；COALESCE 可以接收多个参数，并且是标准 SQL，各数据库通用

**代码题**：下面 SQL 执行后，最后一条查询的结果是什么？（每行用 | 隔开）

```sql
CREATE TABLE contacts (name VARCHAR(10), phone VARCHAR(10), email VARCHAR(20));
INSERT INTO contacts VALUES ('Ann', NULL, 'ann@x.com'), ('Bob', NULL, NULL), ('Cat', '555', NULL);
SELECT name, COALESCE(phone, email, 'N/A') AS contact FROM contacts ORDER BY name;
```

- [x] Ann ann@x.com | Bob N/A | Cat 555
- [ ] Ann NULL | Bob NULL | Cat 555
- [ ] Ann ann@x.com | Bob NULL | Cat 555
- [ ] Ann N/A | Bob N/A | Cat 555

解析：COALESCE 依次检查 phone、email、'N/A'，返回第一个不是 NULL 的值：Ann 没有电话取邮箱，Bob 两者都没有取 'N/A'，Cat 有电话。

**判断题**：
- ✅ COALESCE 返回参数列表中第一个非 NULL 的值 —— 都为 NULL 时返回 NULL
- ❌ 用 AS 给列起别名会永久修改表中的列名 —— 别名只在当前查询中有效
